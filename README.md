# MailMind AI

MailMind AI is a competition-ready AI Email Assistant designed for
hackathons and productivity demonstrations.

## Features

- AI email summarization
- Priority detection
- Email categorization
- Task extraction
- Deadline detection
- Spam detection
- Phishing detection
- Explainable security analysis
- Smart reply generation
- Multiple reply tones
- AI Daily Action Plan
- Follow-up Radar
- Analytics dashboard
- Responsive premium UI
- Deterministic demo mode
- FastAPI backend
- React + Vite frontend

## Architecture

Frontend:

React + Vite

Backend:

FastAPI + Python

AI Layer:

Modular AI service with deterministic analysis.

The application can be connected to an external AI provider through
the AI service layer without changing the frontend architecture.
